## 🚀 Getting Started

### ⚙️ Installation

#### [![yarn](https://img.shields.io/badge/Yarn-3775A9.svg?style=flat&logo=Yarn&logoColor=white)](https://github.com/jessicasantosb/freelance-zarpou)

```sh
❯ git clone git@github.com:jessicasantosb/freelance-zarpou.git
```

```sh
❯ cd freelance-zarpou
```

```sh
❯ yarn
```

```sh
❯ yarn dev
```
